# System Design социальной сети "Travel Social" 

Данный репозиторий содержит работу по проектированию социальной сети для курса по System Design https://balun.courses/courses/system_design

## Функциональные требования:

### Посты
- публикация постов из путешествий с фотографиями, описанием и привязкой к геолокации путешествия;
- редактирование собственных постов; 
- удаление постов;

### Взаимодействия
- Возможность оценивать посты других пользователей
- Возможность оставлять комментарии к постам
- Просмотр комментариев к постам
- Просмотр оценок постов

### Подписки
- Подписка на других пользователей
- Отписка от пользователей
- Просмотр списка подписчиков
- Просмотр списка подписок

### Поиск и навигация
- Поиск популярных мест для путешествий
- Просмотр постов по конкретному месту
- Лента постов с сортировкой в обратном хронологическом порядке
- Фильтр ленты /свои посты/все подписки/конкретный пользователь/все посты/

## Нефункциональные требования:

    Закладываем мощность на первый год работы.
    
 - DAU 10 000 000
 - Аудитория: страны СНГ
 - Данные храним всегда
 - браузер десктоп и мобильный
 - Распределение нагрузки между регионами
 - Горизонтальное масштабирование компонентов системы
 - Адаптивный дизайн для мобильных астройств

 Нагрузка:
 - Создание постов в среднем 1 раз в неделю.
 - Просмотр ленты каждый пользователь 2 раза в день.
 - Сезонный рост просмотров 30%
 - Время загрузки ленты 2 секунды для 95% запросов. 5 сек. 99%
 - Время создания поста 3 секунды для 95% запросов. 5 сек. 99%
 - Кол-во реакций на пост 0,01% DAU
 - Кол-во реакций на пост популярных пользователей 10% DAU
 - Колво комментариев на пост 200
 - Колво комментариев на пост популярного пользователя 100000
 - Колво подписок в среднем до 100 на пользователя
 - Колво подписок в среднем до 5М на популярного пользователя

 Лимиты:
 - У пользователя неограниченное кол-во постов
 - Размер поста не более 4000 символов
 - Кол-во фотографий на пост до 30
 - Размер коментарием не более 200 символов.

 Доступность:

  - SLA: 99.9% (8.77 часов простоя в год)

 Аутентификация и авторизация:

 - JWT токены: время жизни 1 час, refresh token 30 дней
 - 2FA: обязательная для популярных аккаунтов (>10k подписчиков)

 Защита от атак:

  - API: 1000 запросов/час на пользователя
  - Создание постов: 10 постов/день
  - Комментарии: 100 комментариев/час
  - DDoS protection. (cloudeflare)
  - SQL injection защита
 
## Расчёт нагрузки

Посты:
- RPS (w) 10М / 7 / 86400 = 16 RPS
- RPS (r) 10М * 2 / 86400 = 231 RPS
- Traffic (w media) 16 * 30 * 1Mb = 480 MB/s
- Traffic (w meta)  16 * 4Kb = 64 KB/s
- Traffic (r) 231 * 10 * 1MB * 30 = 69 GB/s 

Комментариев:

 Создание
  - Посты в день: 10M / 7 = 1.43M постов
  - Комментарии: 1.43M * 200 = 286M комментариев/день
  - RPS: 286M / 86400 = 3310 RPS

 Чтение
  - Предполагаем 5x больше чтения: 3310 * 5 = 16550 RPS

Остальным трафиком можем пренебречь.
